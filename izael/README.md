# Izael Effemberg - Site Estatico

Site estatico (HTML + CSS puro) recriado a partir da versao Next.js, pronto para GitHub Pages.

## Como publicar no GitHub Pages

1. Copie a foto de perfil do seu projeto Next.js (pasta 'public/images/izael-effemberg-real.png') para a pasta 'images/' deste pacote, mantendo o mesmo nome de arquivo.
2. Suba estes arquivos para a raiz do repositorio 'izael-effemberg.github.io' (ou para a subpasta onde o site ja e servido).
3. Faca commit e push. O GitHub Pages atualiza automaticamente em 1-2 minutos.

## Ajustes recomendados antes de publicar

- Troque 'mailto:seuemail@dominio.com' pelo seu e-mail real (aparece em 3 lugares no index.html).
- Ajuste os links marcados com href="#" (Palestras e eventos, Consultoria em IA, Midia Kit, Propor parceria, Artigos e conteudos, Parcerias e publicidade) para os destinos reais.
- Os icones foram recriados como SVG simples; sinta-se livre para trocar por outros de sua preferencia.

## Estrutura

- index.html - estrutura da pagina
- styles.css - estilos (cores, tipografia, layout)
- images/ - coloque aqui a foto de perfil
